# Atari-100k thesis figures (pgfplots)

Generated by `experiments/src/export_atari100k_pgfplots.py` from the same run
directories, manifests, seed-0 fallback table and seeded bootstrap as
`experiments/atari/exp_atari100k_effrainbow_5seed.ipynb`, so every number here
matches that notebook's printed tables. Re-run the script after any new runs
land (e.g. after rebuilding the ref manifests):

    ~/.conda/envs/low-rank-rl/bin/python experiments/src/export_atari100k_pgfplots.py

## Files

Every figure is split in two:

- `fig_<name>_body.tex` -- the tikzpicture only. **Regenerated on every run.**
- `fig_<name>.tex` -- a `figure` environment with caption and label that does
  `\input{\figtex/fig_<name>_body}`. **Written once, never overwritten**, so edit
  captions, labels and placement there (or in your own figure environments) and they
  survive re-exports. `--rewrite-wrappers` re-creates them from scratch.

| file | what |
|---|---|
| `atari100k_pgfplots_preamble.tex` | packages, the two arm colours, the shared `atari style`, `\figdata` and `\figtex` paths; `\input` it in your preamble |
| `fig_model_free_bars[_body].tex` | Fig. 1: FHR vs published model-free methods, landscape grouped mean/median bars, numbers stacked above each group (CI kept in the data, not drawn) |
| `fig_delta_hns[_body].tex` | Fig. 2: per-game dHNS, sorted, 95 % seed-bootstrap whiskers, hatched = FHR arm short of 5 seeds |
| `fig_learning_curves_showcase[_body].tex` | Fig. 3 (main text): one row of hand-picked games, `--showcase Boxing Breakout ...` (default: 4 largest FHR gains) |
| `fig_learning_curves.tex`, `fig_learning_curves_{a,b}_body.tex` | Figs. 4-5 (appendix): the 26 suite games (Enduro exported, not plotted), mean +- std, two page-sized grids |
| `data/model_free_bars.dat` | rows of Fig. 1 (published means/medians are quoted from the papers, see the script) |
| `data/delta_hns.dat` | rows of Fig. 2: `dhns lo hi` and the split `pos/neg/hatch` columns the bars read |
| `data/curves/<Game>_<arm>.dat` | `step` (x 1e5 env steps), `mean`, `std`, `sem`, `n` on a 200-point grid |
| `make_overleaf_zip.sh` | builds `../atari100k_overleaf.zip` (main.tex at the root + `figures/atari100k/`) |
| `standalone_test.tex` / `.pdf` | compiles the figures on their own (the PDF is the last verified build) |

## Using them in the thesis

    % preamble (the two paths are the defaults; set them only if your layout differs)
    \newcommand{\figdata}{figures/atari100k/data}   % .dat files, relative to the main .tex
    \newcommand{\figtex}{figures/atari100k}        % fig_*_body.tex files
    \input{figures/atari100k/atari100k_pgfplots_preamble}
    % body
    \input{figures/atari100k/fig_model_free_bars}
    \input{figures/atari100k/fig_delta_hns}
    \input{figures/atari100k/fig_learning_curves_showcase}   % main text, one row
    \input{figures/atari100k/fig_learning_curves}            % appendix

If you already have your own figure environments and captions in the thesis, keep
them and just put `\input{figures/atari100k/fig_<name>_body}` where the picture
goes; after a re-export only the `*_body.tex` and `data/` files need re-uploading.

Colours: `fhrcolor` (proposed, tab:blue) and `basecolor` (baseline, tab:orange)
follow D'Oro et al.'s SR-SAC/SAC convention; swap the two `\definecolor` lines in
the preamble to recolour every figure. The curve bands read the `std` column;
change `\thisrow{std}` to `\thisrow{sem}` in `fig_learning_curves.tex` (or in the
script) for standard-error bands. Compile with pdflatex or tectonic; the
groupplot figures take about a minute.
