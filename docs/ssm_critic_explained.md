# The SSM Critic, in detail

*The confirmed winner of the fable campaign: +45.5 AUC on Acrobot, 19/20 fresh
seeds, p < 0.0001, 2.0× fewer episodes to solve threshold. Code:
`src/agents/variants/ssm_critic.py` (~160 lines).*

## 1. The one-sentence version

Instead of *penalizing* the critic when its value estimates wobble off the
low-order recurrence your thesis discovered, we build a critic that is
**architecturally incapable of producing anything else** — its value output is
generated by a tiny linear dynamical system, so every value curve it can emit
already has (approximately) low Hankel rank.

## 2. The architecture, piece by piece

A vanilla PPO critic is a stateless map: `v_t = MLP(s_t)`. Each step is scored
in isolation; nothing ties `v_t` to `v_{t−1}`. The SSM critic replaces this
with a *stateful* pipeline (defaults: feat = 64, rank r = 8):

```
             trunk (MLP, 2×64 Tanh)          recurrence            readout
  s_t  ────────────────────────────►  φ_t ─────────────►  h_t ────────────►  v_t
                                          h_t = a ⊙ h_{t−1} + B φ_t
                                          v_t = C h_t + D φ_t
```

- **φ_t = trunk(s_t)** — a per-state feature vector (64 numbers). This is the
  only nonlinear part.
- **h_t ∈ ℝ⁸ — the state.** Updated by `h_t = a ⊙ h_{t−1} + B φ_t`, where
  `a = sigmoid(decay_logits)` is a *learned per-channel decay* in (0,1)
  (initialized U(0.5, 0.99)) and `B` projects features into the state. Each of
  the 8 channels is an exponentially-decaying memory of the feature stream with
  its own learned timescale — slow channels (a≈0.99) integrate over ~100 steps,
  fast ones (a≈0.5) react within a couple of steps.
- **v_t = C h_t + D φ_t** — the value reads linearly off the state, plus a
  direct skip term `D φ_t` so instantaneous state information isn't forced
  through the memory.
- **h resets to zero at every episode start** and *persists across rollout
  boundaries* mid-episode (an episode that spans two rollouts keeps its
  memory).

This is a diagonal **linear state-space model** — the same mathematical object
at the core of S4/Mamba, cut down to its minimal useful form (real diagonal
transition, no convolution kernels, no gating).

## 3. Why this enforces the low-Hankel-rank prior

Your thesis measurement: value sequences along trajectories approximately obey
`v_t ≈ c₁v_{t−1} + c₂v_{t−2}` — equivalently, their Hankel matrix has rank ≈ 2.

The classical realization-theory fact behind the design: **a sequence generated
by an r-dimensional linear state-space system has Hankel rank ≤ r.** The
`C h_t` component of the critic's output is exactly such a sequence (driven by
the input stream `B φ_t`): its *autonomous* dynamics are `h_t = a ⊙ h_{t−1}`,
an order-r linear recurrence with characteristic roots `a₁…a_r`. So the
smoothness/rank structure of the value curve is a property of the *function
class*, not a training-time regularization pressure:

- The HR penalty said: "produce whatever you like, but pay a fine when the
  Hankel tail is large." Gradients from the fine competed with gradients from
  the value error — and in PPO the fine lost or distorted (your rounds A–G).
- The SSM says: "you physically only have 8 decaying memory channels to write
  the value with." There is no fine, no competing gradient, no gate, no
  schedule — misbehavior is not in the hypothesis space.
- The `D φ_t` skip is the escape valve the prior needs (lesson from the
  LunarLander disaster): a sharp event can enter the value *instantly* through
  the skip, so spikes are representable — but *persistent* value trends must
  flow through the low-rank memory.

## 4. How it plugs into PPO (the engineering that makes it correct)

Three subtleties make a recurrent critic exact inside PPO's rollout-buffer
machinery — all handled in the variant:

1. **Rollout-time values.** During collection, `act()` advances the live
   hidden state under `no_grad` and stores `v_t` in the buffer — these are the
   values GAE uses. `act_and_value_only()` (the bootstrap value at truncation
   boundaries) *peeks* one step ahead without committing the hidden state, so
   the next rollout continues from the correct memory.
2. **Segment-initial hidden states.** The buffer records `h` at the start of
   every episode-segment (`seg_h0`, detached). Mid-episode rollout cuts mean a
   segment's initial memory is *not* zero — it's the carried-over state.
3. **Gradient-time recomputation.** In `update()`, the value loss can't use
   the stored (no-grad) values; the critic re-runs the recurrence *with
   gradients* per segment, starting from the stored `seg_h0`, and regresses the
   recomputed `v_t` on the λ-returns. Verification during implementation: the
   recomputed values match the rollout-time values to ~2×10⁻⁷, and gradients
   flow into `a`, `B`, `C`, `D`. Policy loss and GAE are untouched vanilla PPO.

Cost: the recurrence is 8 multiplies + adds per step; the per-segment Python
loop in the update is the only overhead (wall-clock per Acrobot run: ~40 s vs
~20 s baseline at these budgets — the GRU ablation is far heavier).

## 5. Why it worked where four mechanisms failed

The campaign's post-mortem said value-side interventions failed because (a)
they never changed *behavior* and (b) the penalty pressure was fragile. The
SSM critic dodges both:

- **It changes the advantages, not just a loss term.** GAE is computed from
  the SSM's values. A temporally-coherent value curve produces
  lower-variance, temporally-consistent advantages — which is the signal the
  actor learns from. The structure reaches behavior through the only door PPO
  leaves open.
- **It acts as a learned value filter.** The recurrence is effectively an
  adaptive smoother with learned timescales — the *trainable* generalization
  of the fixed AR(2) filter that AR-GAE applied, without AR-GAE's raw/filtered
  bookkeeping mismatch.
- **The structure-match hypothesis held.** Exploration measured Acrobot's
  value recurrence as genuinely 2nd-order (fitted AR(2) ≈ [1.51, −0.51]) and
  CartPole's as ≈ 1st-order ([1.0, 0]). The SSM was ≈ null on CartPole and
  large on Acrobot — the prior pays where the structure exists. This makes the
  cheap AR-order fit a *predictive diagnostic* for when to deploy the critic.

- **And a bonus nobody registered for:** seed variance collapsed (σ ≈ 11 vs 34
  for baseline; the SSM arm's worst seed beat the baseline's mean). A critic
  that can't produce wild value curves can't send early advantages haywire on
  unlucky seeds — it removes the bad-seed tail.

## 6. What it is NOT (honest limits)

- Not confirmed beyond Acrobot yet — the rank sweep, LunarLander probe, and
  the GRU ablation (nonlinear-recurrence control: is it the *linear low-rank*
  prior or just *recurrence*?) are running now.
- The r ≤ rank bound is exact for the autonomous part; the input-driven
  `B φ_t` stream and the `D` skip mean the full output is *approximately* low
  rank, not exactly — which is what you want (the pure version is HD-PPO's
  mistake).
- Recurrent critics assume within-episode temporal continuity; environments
  with teleporting/reset-heavy dynamics would weaken the prior.
